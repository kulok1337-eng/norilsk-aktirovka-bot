# Бот «Актировки Норильск»

Проверяет официальный сайт Норильска и портал «Северный город», публикует сводки
об актировках в Telegram-канал. Есть админ-панель с кнопками.

## Переменные окружения на BotHost

| Переменная | Пример |
|---|---|
| `BOT_TOKEN` | токен из BotFather |
| `CHANNEL_ID` | `@Norilsk_typical` |
| `ADMIN_IDS` | `8079727075,1979046241` |
| `DRY_RUN` | `true` для первого запуска |
| `DAY_INTERVAL` | `900` |
| `NIGHT_INTERVAL` | `3600` |
| `DATA_DIR` | путь к постоянному хранилищу |
| `ACTIVE_FROM` | `5` |
| `ACTIVE_TO` | `15` |

## Команды для админов

- `/panel` — панель с кнопками
- `/check` — проверить сейчас
- `/status` — состояние источников

## Проверка

1. Запусти с `DRY_RUN=true`.
2. Напиши боту `/panel`, затем `Проверить сейчас`.
3. Убедись, что сводка верная.
4. Переключи режим кнопкой «Режим».

## Ограничение

Разметка сайтов написана под конкретный блок «Информация об актировках».
Если сайт изменит структуру, бот сообщит об ошибке и не придумает результат.
